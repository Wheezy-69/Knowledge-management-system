# Knowledge Vault expansion checkpoint — 2026-11-06

Branch: `feat/backup-search-filters`. This is an implementation checkpoint,
not a claim that all documentation and browser verification are complete.

## Implemented so far

- Portable JSON export, checksum/relationship validation, and append-only restore
  with fresh IDs and attachment filenames; restore does not replace existing data.
- Broader problem search, bounded result previews, and combined filters.
- Reusable tag catalog, assignment, rename, and removal.
- Reciprocal related-problem links with duplicate/self-link protection.
- Bounded, whitespace-sensitive code comparison without changing stored snippets.
- Ordered text/code blocks and non-destructive copying of legacy fields.
- A graph derived from stored tags/links, including isolated problems and limits.
- Line wrapping and exact-source clipboard copying with manual selection fallback.

The additive migration has run locally. Original problem fields and JSON tags
remain. A private portable backup was created and validated before migrating;
backup files and the SQLite database are ignored by Git and are not in this commit.

## Verification at checkpoint

- Backend suite: 77 tests passed, 612 assertions.
- PHPStan passed; PHP formatting passed after automatic fixes.
- Earlier frontend checks/build passed, including 8 code/highlighting/copy tests.
  A final rerun after the last small UI edits remains part of completion.

## Still pending

- Update the feature guides, database/architecture overview, and TypeScript guide
  to describe the expansion and portable backup format fully.
